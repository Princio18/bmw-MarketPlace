CÔTÉ CLIENT
 1. All Models → choisir un modèle → Configure (configurer jantes, options, accessoires).
 2. Add to cart / Continue → arriver au panier.
 3. Panier → Request an offer (⚠️ ceci ne paie pas : ça crée une demande).
 4. Remplir le formulaire (coordonnées, préférence de contact) → Confirm request.
 5. Attendre. La demande part à l'admin.
 6. La demande est traitée → le client reçoit un email d'offre.
 7. Se connecter → My requests → voir la demande passée à « offer sent » → View offer.
 8. Sur la page de l'offre : lire le décompte → cocher I accept the terms → Pay.
 9. Redirection vers Stripe → saisir la carte → Pay.
10. Retour sur Order confirmation (patiente quelques secondes pendant la vérification).
11. View order → suivre l'avancement (paid → in preparation → ready → delivered).
12. Quand c'est ready : voir le VIN + le lieu et la date de remise → se présenter au centre.
13. À la remise : récupérer le véhicule (le statut passe à delivered).
14. Optionnel : laisser un avis / télécharger le reçu.
    
CÔTÉ ADMIN (vendeur)
 1. Se connecter → Requests.
 2. Voir la nouvelle demande → View.
 3. Send message (le statut passe à « We've been in touch ») — ou contacter par téléphone.
 4. Dans le bloc Offers : ajouter des ajustements si besoin → Preview (vérifier le total).
 5. Create offer → l'email part automatiquement au client. (Possibilité ensuite : Resend / Withdraw.)
 6. Attendre que le client paie.
 7. Une fois payé : notification New order. Aller dans Orders.
 8. Ouvrir la commande → View.
 9. Faire avancer le statut : In preparation (préparation).
10. Passer à Ready for handover → saisir le VIN (17 caractères) + la date/heure de remise → valider. (Le client reçoit un email.)
11. À la remise effective : passer à Delivered. (Email au client.)
12. Si besoin : Resend receipt, ou Refund en cas d'annulation.
    
LE POINT DE JONCTION
- Le client clique Request an offer → l'admin le voit dans Requests.
- L'admin clique Create offer → le client reçoit l'email → clique View offer → Pay.
- Le client paie → la commande apparaît dans Orders de l'admin.
- L'admin clique Ready for handover → le client voit le VIN/la date dans My orders.
- L'admin clique Delivered → le client a son véhicule. Fin.
